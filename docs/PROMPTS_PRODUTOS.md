# Prompts de imagem — 15 produtos novos (RaitoCorp)

15 produtos de iluminação foram inseridos no catálogo. Abaixo, **1 prompt por produto** para gerar a foto numa IA de imagem (Gemini, Midjourney, DALL·E, ModelScope/Qwen-Image, etc.).

**Dicas de uso:**
- Os prompts estão em inglês (funcionam melhor na maioria das IAs).
- Estilo pedido: **foto de produto para e-commerce** — fundo limpo/neutro, produto centralizado, bem iluminado.
- Depois de gerar, suba a imagem no Cloudinary (cloud `dvt0gyhlr`, preset `raitocorp-mobile`) e troque o `image_urls` do produto no admin do app.
- Cada bloco traz o **nome** e os **atributos** do produto (pra você conferir/ajustar o prompt se quiser).

### Como trocar a imagem do produto depois de gerar
1. Gere a imagem com o prompt acima.
2. Suba no Cloudinary (ou use a tela de **admin** do app, que já integra upload).
3. No admin, edite o produto e cole a URL no campo de imagem — ou peça pro assistente atualizar via SQL com o `image_urls`.

> Todos os 15 já estão **ativos** no catálogo com uma imagem placeholder. É só substituir.
